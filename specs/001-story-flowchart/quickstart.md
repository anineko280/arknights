# クイックスタート・検証ガイド: ストーリーのフローチャート

## 目的

本ガイドは、実装されたストーリーフローチャート機能が受入基準および仕様を満たしているかをエンドツーエンドで検証するための手順書です。

---

## 1. 前提条件・セットアップ

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:5173`（または出力されたローカルURL）を開きます。

---

## 2. 自動テストによる検証 (TDD)

```bash
# 単体テストおよび契約テストの実行
npm run test

# 型チェックの実行
npm run typecheck

# 静的解析・リンターの実行
npm run lint
```

---

## 3. 手動シナリオ検証手順

### シナリオ 1: フローチャートの閲覧とインタラクション (US-1 / P1)
1. 画面初期表示時に、メインテーマ（0章〜）および主要サイドストーリーのノード群が2Dキャンバス上に整列表示されることを確認。
2. マウスドラッグでキャンバスをパン移動し、ホイール操作でズームイン/ズームアウトが滑らかに動作することを確認。
3. 任意のストーリーノード（例: 「闇夜に生きる」または「第7章」）をクリックし、前提条件ノードがハイライトされ、サイドパネルに概要が表示されることを確認。

### シナリオ 2: 読了ステータスの更新とネタバレ防止 (US-2 / P2)
1. 詳細パネルでステータスを「読了」に変更。該当ノードが「読了済み」カラー（例: シアン/グリーン）に変化することを確認。
2. ヘッダーの「ネタバレ防止」トグルがONの状態で未読ノードを開き、核心的なあらすじがマスク（伏字）されていることを確認。
3. マスク部分をクリックして一時的に表示できることを確認。

### シナリオ 3: フィルタリングと検索 (US-3 / P3)
1. フィルターメニューで「メインテーマのみ」を選択し、サイドストーリーが非表示になりメイン章の繋がりだけが表示されることを確認。
2. 勢力フィルターで「カズデル」または「ウルサス」を選択し、関連ストーリーが抽出されることを確認。
3. 検索バーに「チェルノボグ」と入力し、該当ノードが即座にフォーカスされることを確認。

### シナリオ 4: JSONバックアップと復元 (US-4 / P3)
1. 設定メニューから「進捗データをエクスポート」をクリックし、`arknights-story-progress.json` がダウンロードされることを確認。
2. 「全進捗をリセット」をクリックして未読状態に戻す。
3. 「進捗データをインポート」から先ほど保存したJSONファイルを選択し、読了状態が完全に復元されることを確認。
